# 怎么加音乐

## 三步

1. 把 `.mp3` 文件放进 **`assets/music/`** 目录
2. 打开 **`assets/music/playlist.json`**，照着已有的格式加一条
3. 保存、上传这两个文件，刷新网页

---

## 格式 A：最省事（只写文件名）

只有一两首歌、或者不在乎显示名，就写成一个字符串数组：

```json
[
  "bgm.mp3",
  "bgm2.mp3",
  "bgm3.mp3",
  "bgm4.mp3"
]
```

- 会自动从 `assets/music/` 找文件
- 显示名 = 文件名去掉扩展名
- **最容易出错的地方就是这个数组**：每行末尾要有逗号，**最后一行不能有逗号**

---

## 格式 B：带标题 / 作者 / 图标（推荐）

```json
[
  {
    "src": "assets/music/bgm.mp3",
    "title": "Blush",
    "artist": "BGM 01",
    "emoji": "🎧"
  },
  {
    "src": "assets/music/bgm2.mp3",
    "title": "NIGHT DANCER",
    "artist": "BGM 02",
    "emoji": "🌙"
  }
]
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `src` | ✅ | 文件路径。也可以只写文件名（`bgm2.mp3`），会自动补 `assets/music/` |
| `title` | 可省 | 歌名；省略则用文件名 |
| `artist` | 可省 | 副标题，显示在歌名下方 |
| `emoji` | 可省 | 封面上那个图标 |

---

## ⚠️ 最容易犯的三个错

### 1. 两条记录之间漏逗号（就是前几天遇到的那个）

```json
  {
    "src": "assets/music/bgm3.mp3"
  }          ← 这里少一个英文逗号
  {
    "src": "assets/music/bgm4.mp3"
  }
```

正确写法是 `},` 再换行写下一首。

> 现在代码会自动尝试修复这种"对象之间漏逗号"的错误，并在播放器里提示
> 「歌单格式有自动修复（可能漏了逗号）」。但**请还是把它改对**，不要依赖自动修复。

### 2. 最后一个后面多写了逗号

```json
  {
    "src": "assets/music/bgm4.mp3"
  },        ← 最后一个不能有逗号
]
```

### 3. 文件名大小写 / 空格对不上

- `BGM4.mp3` 和 `bgm4.mp3` 在服务器上是**两个不同文件**
- 文件名带空格要写成 `my%20song.mp3`，或者干脆改成下划线 `my_song.mp3`
- 建议全小写、只用 `a-z 0-9 _ -`

---

## 出错了怎么排查

播放器面板里会直接显示原因，不用打开控制台：

| 面板提示 | 意思 | 怎么办 |
|---|---|---|
| 歌单读取失败：… | `playlist.json` 打不开或格式坏了 | 按上面的提示改 JSON |
| 歌单格式有自动修复 | 漏逗号之类，已自动救回来 | 建议改对，别依赖修复 |
| 无法播放「XX」：文件可能没上传 | 音频文件 404 或格式不支持 | 检查文件是否真的上传了 |
| 有 N 条曲目缺少文件名 | 某条记录没写 `src` | 补上文件名 |

右上角那个数字是**识别到的曲目数**。如果它显示 `1` 而你有好几首，就是歌单没读进来。
